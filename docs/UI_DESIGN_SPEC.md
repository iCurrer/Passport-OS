# Passport OS V2 — UI 设计规范（UI_DESIGN_SPEC）

> 本文件是 240×320 每一个页面的坐标、字体、颜色、间距的**单一设计权威**。
> V2 采用**上下翻页（Vertical Page Navigation）** 而非 App Grid，共 8 页，页面循环。
> 与现有旧 `ui_pixel` 浅色像素风冲突时，以本文 + `docs/PASSPORT_OS_V2_AI_IMPLEMENTATION_PLAN.md` 的 V2 深色规范为准。
> 坐标系：屏幕左上角为 (0,0)，右为 +x，下为 +y，单位 px。

---

## 1. 画布与骨架

```
┌────────────────────────────┐
│ Header                0–35 │
├────────────────────────────┤
│ Content             36–271 │
│                            │
│                            │
├────────────────────────────┤
│ Footer(Page Indicator)272–319│
└────────────────────────────┘
```

- 画布：`240 × 320`。左右安全边距：`16 px`。
- Header：0–35。左侧标题（左对齐于 x=16, 垂直居中偏上），右侧电量条 + 百分比，底部 y≈35 分隔线。
- Content：36–271，页面主体。
- Footer：272–319，Page Indicator；垂直居中于 296。
- 底部分隔线 y=271（Footer 顶缘）。

### 设计系统常量（V2 design-system 草案，TASK-01 具体落地）

| 常量 | 值 |
| --- | --- |
| `SCREEN_W` / `SCREEN_H` | 240 / 320 |
| `MARGIN_X` | 16 |
| `HEADER_H` | 35（Header 0–35） |
| `CONTENT_Y` / `CONTENT_H` | 36 / 236（→ 271） |
| `FOOTER_Y` | 272 |
| `HEADER_LINE_Y` | 34（分隔线） |
| 标题字体 | `badge_font_gb2312_small`(14px) 或 16px（TASK-01 定） |
| 正文大字 | `badge_font_gb2312`(30px) |
| 正文小字 | `badge_font_gb2312_small`(14px) |
| 百分比/数字 | `lv_font_montserrat_14`(ASCII) |
| 电量条 | x=158 起（外框 20×10 @158,14，内芯 16×6 @160,16，百分比 @186,12），与现有 `ui_header_bar` 一致 |

### 配色（V2 深色极简，覆盖旧 ui_pixel 浅色）

| 语义 | HEX | 用途 |
| --- | --- | --- |
| 背景 | `#000000` | Header/Content 背景 |
| 主文字 | `#FFFFFF` | 姓名、标题、数值 |
| 次要文字 | `#8A8A8A` | 次级说明、标签 |
| 强调 | `#4CD964` | 状态激活、选中、指示、高亮 |
| Warning | `#FF9F0A` | 低电量/警告 |
| Danger | `#FF453A` | 卸载错误、低电、Game Over |
| 分隔线 | `#1F1F1F` | 分隔条、灰卡边线 |
| 卡片底 | `#111111` | 内容卡片背景 |

> 旧 `BADGE_BG_COLOR 0x1E352C`（磨砂绿）与 V2 `#000000` 冲突。**改造到对应 TASK 时以 V2 为准建立新 design-system；先保留旧 `ui_pixel` 保证编译与旧功能不被破坏，不要立刻删除。**

### 字体事实（红线，见 HARDWARE_REFERENCE §3）
- 自定义字库必须用与 LVGL 9.5 匹配的 `lv_font_conv` 生成，`bitmap_format=1`。
- 必须带 ASCII `0x20–0x7E`。换字体前务必先在硬件验证中文/英文/数字。

- `lv_obj_t *ui_block(parent,x,y,w,h,color)` — 纯色块。

## 4. Page Indicator（Footer）

底部居中，8 个圆点表示 8 页当前页位置，当前页为实心、其余空心：

```
        ● ○ ○ ○ ○ ○ ○ ○     ← 第 1 页
        ○ ○ ● ○ ○ ○ ○ ○     ← 第 3 页
```

- 圆点直径 6px，间距 12px，整组水平居中于 240，垂直居中于 y≈296（Footer 272–319 的中间）。
- 8 点总宽 = 7×12 + 6 = 90px，起 x = (240−90)/2 = 75。
- 第 i 点中心 x = 75 + 6 + i×12；圆点矩形 x = 75 + i×12，y = 293，6×6。

## 6. PAGE 0 — HOME / IDENTITY（默认页）

目标：一眼看到“这是我的电子身份”。

```
┌────────────────────────────────────────┐
│  JOHN PASSPORT                    86%  │ ← Header 0–35
├────────────────────────────────────────┤
│                                        │
│          ┌─────────┐                   │
│          │ AVATAR  │  90x90 居中        │ ← y=54,顶到分隔线34间距20
│          └─────────┘                   │
│          JOHN LEE       (30px 主文字)   │ ← y=164,头像底144到姓名间距20(上下等距)
│          ACCOUNTING     (14px 次文字)   │ ← y=198
│          ● AVAILABLE    (14px 强调)     │ ← y=230
│                                        │
│          ● ○ ○ ○ ○ ○ ○ ○             │ ← Footer
└────────────────────────────────────────┘
```

| 元素 | 内容 | 坐标 / 字号 | 颜色 |
| --- | --- | --- | --- |
| Header 标题 | 顶部文字（可自定义） | 左缘 x=16，y=13，14px | 主/次文字 |
| 电量 | 右上方 | 见骨架 | — |
| 头像 | 默认图/自定义 80×80 → 90×90 | 居中 x=75，y=54（90×90） | — |
| 姓名 | name | 居中，y=164，30px | 主文字 |
| 职位 | title | 居中，y=198，14px | 次要 |
| 状态 | status | 居中（前置状态圆点），y=230，14px | 强调 |
| Footer | Page Indicator | y≈296 | — |

> 头像 90×90 垂直居中于 Header 分隔线(y=34)与姓名(y=164)之间：头像顶到 34 的间距 = 头像底(144)到姓名的间距 = 20，上下等距。验收：无越界、中英文正常、电量正常、头像区正常、姓名/职位/状态/指示器正常。

> 现状对比（V1）：当前 `badge_ui.c` 是“左头像+右信息列”，非垂直居中布局，且无 Page Indicator；TASK-03 按上面垂直版改造。

| 元素 | 坐标 |
| --- | --- |

| 元素 | 坐标 |
| --- | --- |
