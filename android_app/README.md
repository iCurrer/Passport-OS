# FoloToy Badge 安卓端

配套名牌固件的 BLE 自定义 App(Kotlin)。可手动扫描、连接名牌,写入/读取 4 个字段:
姓名、顶部文字、职位、状态。**App 退出时自动关闭蓝牙连接并释放资源**。

## 用 Android Studio 编译

1. 用 Android Studio 打开本目录(`File > Open` 选择 `android_app` 文件夹)
2. 等 Gradle 同步完成(首次会下载依赖,需联网)
3. `Build > Build Bundle(s) / APK(s) > Build APK(s)`
4. 生成的 APK 在 `app/build/outputs/apk/debug/app-debug.apk`,传到手机安装

> 若你的 Android Studio 版本较新,提示升级 Gradle Plugin / Kotlin 版本,直接升级即可(本工程用 AGP 8.5.2 / Kotlin 2.0.20)。

## 使用步骤

1. 手机开启蓝牙
2. 名牌开机(处于广播状态,屏幕显示名牌即广播中)
3. 打开 App,授予定位/蓝牙权限
4. 点「扫描并连接」→ 自动找到 `FoloToy-Badge` 并连接
5. 连接后可「读取当前值」或填写后「写入名牌」
6. 关闭 App → 连接自动断开、蓝牙释放

## 与固件的协议(UUID)

服务 `0000FFE0-0000-1000-8000-00805F9B34FB`,内含 4 个可读写特性:

| 字段 | 特性 UUID |
|---|---|
| 姓名 | `0000FFE1-0000-1000-8000-00805F9B34FB` |
| 顶部文字 | `0000FFE2-0000-1000-8000-00805F9B34FB` |
| 职位 | `0000FFE3-0000-1000-8000-00805F9B34FB` |
| 状态 | `0000FFE4-0000-1000-8000-00805F9B34FB` |

写入内容为 UTF-8 字符串。

## 注意

- 名牌的中文字库覆盖 **GB2312 一级常用字**。写入字库之外的中文会显示为空白，需扩展固件字库。
- 名牌处于深度睡眠时不广播,需先唤醒(按任意键)。
